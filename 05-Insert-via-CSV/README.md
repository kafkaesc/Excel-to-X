# Insert via CSV

Built by Jared Hettinger

This unit contains a node project that can set up a local sqlite database. Once the database is ready, running the program will parse data from the `in.csv` file and insert values into the database.

## Database Setup

1. Navigate to the `/05-Insert-via-CSV/` folder
2. Run `npm run setup-db`

## Run the Project

1. Navigate to the `/05-Insert-via-CSV/` folder
2. Run `npm start`

## Clean

1. Navigate to the `/05-Insert-via-CSV/` folder
2. Run `npm run clean`

## Technologies Used

1. [Node](https://nodejs.org)
2. [SQLite](https://sqlite.org)
3. [csv-parse](https://www.npmjs.com/package/csv-parse)
4. [CSV](https://datatracker.ietf.org/doc/html/rfc4180)
